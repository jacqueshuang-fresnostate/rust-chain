# 代理秒合约倒计时

## 范围与口径

- 仅代理团队用户秒合约列表新增“倒计时”列。
- opened 订单按 expires_at 毫秒截止时间与当前时间计算，每秒更新，不依赖接口轮询。
- 未满一秒向上取整；到期显示“待结算”，不擅自标为已结算、不调用结算接口。
- settled/manual_review 显示横线；切换标签、翻页、刷新、换用户和卸载清理旧计时器。
- 从后台恢复或获得焦点时重新按实际时钟校正，避免逐秒递减造成累计误差。
- 不变更后端、权限、钱包、其他订单视图或现有刷新策略。

## 验收

- [x] 进行中订单显示并持续更新分秒（超过一小时含小时）。
- [x] 到期不出现负数；历史/人工复核不倒计时。
- [x] 假时钟测试覆盖正常走时、到期、切页返回、后台恢复、刷新后结算及卸载。
- [x] 类型检查、lint、定向测试和本地浏览器检查，更新进度。
