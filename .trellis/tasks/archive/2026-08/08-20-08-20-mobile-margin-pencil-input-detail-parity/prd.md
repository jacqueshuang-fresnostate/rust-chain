# 手机端杠杆页 Pencil 1:1 输入与细节修复

## 背景

手机端 `/trade/:symbol?mode=contract` 已具备真实行情、杠杆产品、钱包、订单与风险数据，但当前生产页面仍未完全复刻用户在 Pencil 中选中的杠杆页面。最明显的问题集中在价格/保证金输入框，另外开平仓选中态、最优价按钮、比例滑杆、下单按钮文案和弹层初始状态也存在视觉或交互偏差。

## 唯一设计基线

- Pencil 文件：`mobile/pencil/hippo-mobile-uiux.pen`
- 主页面：浅色 `cjzfi`、深色 `p6GfgT`
- 交易对弹层：浅色 `YuKtQ`、深色 `Crw8v`
- 杠杆弹层：浅色 `R8t0p`、深色 `f0L8yf`
- 保证金模式弹层：浅色 `PKAcD`、深色 `aNuw6`
- 目标视口：390×920；生产页面使用真实安全区，不复制 Pencil 的 28px 伪系统状态栏。

## 功能与视觉要求

1. 保留当前真实 API、WebSocket、产品能力、钱包、订单、风险和路由语义，不复制 Pencil 示例价格、余额、仓位或能力。
2. 390px 下保持已确认的 `14 / 202 / 10 / 150 / 14` 双栏、58px Header、460px 交易模块、450px 控制台/盘口与 44px 标签栏。
3. 开仓选中态必须使用 Pencil 的薄荷绿色实心面和深色文字；平仓及未选态使用主题表面与次级文字。
4. 当后端同时支持限价和市价时，初次进入优先展示 Pencil 主稿中的限价单；若当前选择仍有效则保留，若只支持一种类型则严格使用后端唯一能力，空能力仍为不可用。
5. 订单类型属于本地表单状态，访客也可打开订单类型弹层并显式选择；提交订单、修改杠杆和修改保证金模式仍要求登录。
6. 价格输入框严格采用 138×56 的双行结构：可见标签为“价格（结算资产）”，数值使用 17px 数据字体；闲置态无可见描边，聚焦/错误态由完整且不改变几何的外壳焦点层表达，内部 input 不绘制第二层边框或阴影。
7. 右侧 58×56 按钮使用 Pencil 的“最优价”文案、12px 字体和 8px 圆角；仅限价且有真实 BBO/最新价时可用。
8. 保证金输入框严格采用 202×46 的双行结构：可见标签为“保证金（结算资产）”，输入值使用 15px 数据字体，右侧显示真实结算资产；不得把后端保证金金额伪装成基础币数量。
9. 输入框必须支持触控聚焦、光标、删除、粘贴、小数点中间态和 `aria-invalid`；手动输入清除比例档位，错误状态不得改变双栏宽高或挤压盘口。
10. 五档比例控件保留 `0/25/50/75/100` 的 44px 触控目标和无障碍名称，但视觉只呈现 Pencil 的轨道与五个节点，不额外显示百分比文字。
11. 止盈止损复选框、可用余额、摘要和按钮保持 Pencil 的轨道位置；主按钮文案改为“开多 {leverage}x / 开空 {leverage}x”，不再显示“买入开多 / 卖出开空”。
12. 交易对弹层的搜索框闲置态必须与 Pencil 的表面、1px 中性描边和 10px 圆角一致；初次打开不应因自动聚焦而把未操作画面渲染成高亮输入态，仍须保留完整键盘焦点路径。
13. 当前交易对筛选复选框、全部平仓、筛选和历史入口的明暗主题状态应与 Pencil 对应；禁止使用示例持仓填充访客空状态。
14. 320、390、448px 均不得出现横向溢出；Header 保持 sticky 和 z-index 70；减少动态效果时移除非必要动画。

## 验收标准

- 源码测试锁定上述 Pencil IDs、限价优先策略、访客订单类型弹层、双行输入结构、最优价文案、无视觉百分比文字和主按钮文案。
- 输入框聚焦时外壳矩形尺寸不变，嵌套 input 的 border/outline/box-shadow 均为零；空值、合法小数、非法值和超精度值均有正确状态。
- Ego Browser 在 390×920 浅色/深色对照主页面，在 320×720 与 448×900 验证响应式；点击订单类型、限价输入、保证金输入、BBO、比例节点和弹层关闭路径。
- `document.documentElement.scrollWidth === innerWidth`，主要控件不被盘口遮挡，长短按钮完整可见。
- `npm --prefix mobile run type-check`、相关聚焦测试、Mobile 全量测试、PWA 与 Tauri 构建通过。

## 范围外

- 不修改 Pencil 原文件。
- 不修改后端保证金金额模型，不新增止盈止损或策略撮合。
- 不纳入或改动既有未跟踪目录 `mobile/pencil/docs/`。
