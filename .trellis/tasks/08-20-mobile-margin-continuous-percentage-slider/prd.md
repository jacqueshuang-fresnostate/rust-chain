# 优化杠杆连续百分比滑杆、盘口比例与持仓同步

## 背景

手机端杠杆下单区的 `contract-percentage` 当前由 `0/25/50/75/100` 五个离散按钮组成。用户需要移除所有区间点，改为可拖到任意百分比的连续滑杆。

同一工作台还存在异步强平后的状态同步缺口：后台 worker 已把仓位迁移为 `liquidated`，但页面定时任务只刷新单仓风险快照，没有重新读取杠杆钱包与 `opened` 持仓，因此已爆仓仓位会一直残留到用户主动下单、平仓、切换模式或重新进入页面。

## 范围

- 仅修改杠杆下单区百分比控件；现货百分比按钮保持不变。
- 使用原生 `input[type="range"]` 提供拖动和键盘语义。
- 滑杆范围为 0–100，按 1% 连续调整，并实时复用现有真实余额、产品上限和金额计算链路。
- 移除五个可见区间点和对应按钮命中层，保留单一轨道、进度和滑块。
- 保留至少 44px 的触控高度、可见焦点、禁用状态、深浅主题和窄屏适配。
- 跟进优化同一杠杆工作台的 `order-book__mini-ratio`：以单一买卖力量轨道替代拥挤的行内比例，保留实时 B/S 数据并提升深浅主题可读性。
- 将现有 5 秒风险刷新升级为杠杆账户后台对账：以 `/margin/wallets` 返回的杠杆钱包和 `opened` 持仓作为同一轮权威快照，再为仍存活的已成交仓位刷新风险。
- 杠杆页面在登录态订阅后端自动绑定的个人 WebSocket `/ws/private?token=<access_token>`；收到 `margin.position.liquidated` 后立即发起静默账户对账，连接建立或重连后也主动补一次 REST 对账。
- 私有 WebSocket 仅作为易失刷新提示，不直接用事件载荷改写钱包或持仓；保留 5 秒 REST 轮询覆盖断线、漏消息与服务重启。
- 后台对账不切换首屏 loading、不清空最后一次成功数据，也不在瞬时网络错误时闪烁错误态；首次加载及用户主动下单、平仓、撤单后的显式刷新保留既有反馈。
- 请求必须隔离退出登录、账号切换、现货/杠杆模式切换、组件卸载以及请求乱序；慢速旧响应不得把已消失的强平仓位写回。
- 页面从后台恢复可见时立即补一次账户对账；隐藏页面不继续发起新的周期请求。

## 验收标准

- [x] 杠杆模板不存在 `v-for="value in [0, 25, 50, 75, 100]"`。
- [x] 杠杆百分比控件为 `min=0`、`max=100`、`step=1` 的 range input。
- [x] 任意整数百分比都会实时更新保证金金额，且仍受真实杠杆钱包可用额与产品 `maxMargin` 限制。
- [x] 不显示区间圆点，只显示轨道、当前进度、单个滑块和当前百分比。
- [x] 键盘、屏幕阅读器、44px 触控、焦点、禁用及登录入口可用。
- [x] 手工编辑金额清除滑杆选择状态；现货百分比行为不变。
- [x] 聚焦回归、Mobile 全量测试和类型检查通过。
- [x] B/S 比例使用实时盘口数量计算，买卖百分比之和稳定为 100%。
- [x] 比例区采用上下两层紧凑结构：语义标签在上、单一双色力量轨道在下，不再显示割裂的短线。
- [x] 比例区在 150px 盘口列、320px 页面以及深浅主题下无溢出，并具有可理解的单元格辅助文本。
- [x] 后台强平后，无需重新进入页面，当前持仓最迟在下一轮 5 秒对账后移除，杠杆钱包余额同步采用同一接口结果。
- [x] 登录且位于杠杆页面时连接用户专属 `/ws/private`；强平推送会立即触发 REST 对账，现货、访客、退出登录和卸载会关闭连接。
- [x] 私有连接使用当前 access token，重连时读取最新持久化 token；具备当前 socket 身份保护、心跳、有界退避和幂等停止，并忽略 pong、确认、错误与畸形帧。
- [x] WebSocket 初次连接/重连后执行 REST 对账；即使推送断线或丢失，5 秒轮询仍能收敛到权威状态，事件字段本身不直接改变资金数据。
- [x] 对账成功后只为当前仍为 `opened` 且已成交的仓位保留/请求风险快照，已强平仓位的旧风险数据被清理。
- [x] 周期对账单飞执行；回前台立即对账；隐藏、现货模式、访客态和卸载状态不发起新的杠杆账户请求。
- [x] 后台请求失败保留最后一次成功的持仓和钱包，不触发首屏 loading/error 闪烁；后续周期可自动恢复。
- [x] 慢速旧请求在账号、模式或生命周期变化后返回时被判定为 stale，不能覆盖更新后的页面状态。
