# 代理团队用户金融明细

## 范围

从代理后台团队用户的现有明细入口，提供钱包账户、秒合约订单、杠杆订单、杠杆持仓、现货订单五个只读标签。
保留已有用户及代理功能，不改变交易、撮合、结算或资金规则，不新增数据库迁移。

## 实现口径

- 钱包保留现货与杠杆账户、可用/冻结/锁定余额。
- 秒合约默认全部，支持进行中、已结算、人工复核筛选。
- 杠杆订单复用 margin_positions 的持久化记录。opened 且 entry_price 为空表示待成交委托；持仓视图只列 entry_price 非空的记录。
- 杠杆订单支持待成交、持仓中、已平仓、已取消、已强平筛选；不伪造独立订单账本或成交时间。
- 现货订单展示买卖方向、类型、价格、触发价、委托/成交数量、状态及时间。
- 五个标签独立分页、惰性加载，提供刷新和加载失败后的重试。
- scope 仅来自代理令牌；记录查询和 COUNT 各自重复子树约束。越权和不存在统一 404。
- 金额使用 Decimal 字符串，时间使用 Unix 毫秒。查询不建钱包、不更新利息、不触发成交或结算。
