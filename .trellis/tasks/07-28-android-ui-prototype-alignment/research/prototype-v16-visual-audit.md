# 公开原型版本 16 与真实安卓端视觉审计

## 参考

- 公开原型：`https://hippo-mobile-signal-2026.ikuboy.chatgpt.site/?version=16`
- 真实本地端：`http://127.0.0.1:1611/#/`
- 审计视口：390x844
- 原型样式资源：`/assets/index-SmgSKqUK.css`
- 原型品牌资源：`/hippo-logo-compact.png`，500x500 RGBA

## 首屏同屏结论

### 原型

- 官方横向 HIPPO Logo 位于左上，底部有短橙色信号线。
- 右侧为两个独立圆形工具按钮，通知使用小橙色未读点。
- 搜索框与扫码圆形按钮在第二工具行，背景存在低对比纸面网格。
- 资产区为白色明亮面板：左侧总资产大数字，右侧今日收益，底部完整绿色折线。
- 主动作是绿色“买币”和浅色“充币”双栏。
- 八项快捷入口是 4x2 圆形图标矩阵。
- 行情日报使用整块高饱和橙色信号面。
- 底部导航为七栏雕刻式异形结构，中间秒合约入口抬升。

### 当前真实端

- Header 使用三列居中小 Logo，缺少原型左对齐品牌锁定和橙色基线。
- 搜索只有普通矩形控件，没有独立扫码按钮和网格工具层。
- 资产区是黑色大面板，没有收益数字、周期切换和完整曲线。
- 主动作使用橙色“充值”和灰色“交易”，与原型买币/充币不一致。
- 快捷入口虽为 4x2，但尺寸、颜色、垂直节奏和原型不同。
- 行情日报只保留了窄条，没有原型信号块的视觉冲击。
- 异形导航使用类似轮廓，但高度、中心切口和图标状态仍不一致。

## 原型二级与业务页面语法

- `.secondary-header`：不透明 sticky Header，左返回、中间三层信息、右动作。
- `.secondary-content`：低圆角、细边界、紧凑纵向工作台。
- `.field`：完整容器聚焦、错误/提示/完成占位稳定。
- `.confirmation-layer`：底部确认层、遮罩、焦点圈和安全区。
- `.product-hub-matrix`：六列逻辑网格，重点产品跨 3 列，次级产品跨 2 列。
- `.message-center`、`.borrowing-overview`、`.protection-overview`：使用顶部信号色和
  业务摘要，不是通用卡片列表。
- `.seconds-market-board`：秒合约独立市场板，浅色为明亮面板，深色为独立暗板。

## 安卓交付风险

- Tauri Android 的 `beforeBuildCommand` 已指向 `npm run build:tauri`，正常构建会把
  最新 `mobile/dist` 打入 APK；仅启动旧 APK 不会自动获得浏览器中的更新。
- 当前 Debug APK 生成于 2026-07-28 07:36，但公开原型对齐提交晚于该时间，因此
  必须重新构建 APK。
- 发布构建不能使用设备 loopback 后端；本次视觉验收可使用 Debug 构建和开发代理，
  但发布包仍需真实 HTTPS 后端域名。

## 实施建议

- 先重构共享令牌和壳层，再改一级页面，最后统一二级页，避免每页复制颜色。
- 首页必须重写结构，不可继续在现有黑色资产块上做局部换色。
- 业务逻辑、API 和状态计算保留，只替换模板结构和局部样式。
- 建立源代码合同测试和浏览器截图检查，防止后续再次只做“风格接近”。
