# 新增手机端 GSAP 启动首屏

## Goal

为生产 `mobile/` Vue/Tauri/PWA 客户端增加一个使用 GSAP 驱动的品牌启动首屏。每次新的应用会话首次进入时播放一次，随后无缝揭示当前真实路由页面；同一会话中的路由切换不重复播放。

## Requirements

- 使用官方 GSAP 依赖，不手写动画引擎。
- 新增独立 `LaunchIntro` 组件并在 `App.vue` 手机画布中挂载。
- 使用现有 HIPPO 横版 Logo、网格、绿色/蓝色/珊瑚信号色和硬切幕帘视觉，不使用表情或手绘 SVG。
- 动画总时长控制在约 2 秒，不阻塞 API、鉴权、Pinia 或路由初始化。
- 使用 `sessionStorage` 版本化键控制“每个应用会话首次进入一次”，不能在路由切换时重播。
- 存储不可用时保持可用，不能因隐私模式异常阻止应用进入。
- `prefers-reduced-motion: reduce` 时不播放运动序列，立即完成并记录会话状态。
- 播放期间锁定页面滚动，完成或组件卸载时必须清理 GSAP timeline、上下文、定时状态和滚动锁。
- 首屏为装饰性过渡，不增加可聚焦控件，不延迟辅助技术访问真实页面。
- 覆盖 320px 到 448px 手机宽度、顶部/底部安全区、明暗主题和 Tauri/PWA。

## Acceptance Criteria

- [x] `gsap` 作为生产依赖安装并由启动组件直接使用。
- [x] 首次会话渲染首屏，同会话后续挂载或路由切换跳过。
- [x] 存储异常和低动态模式均立即安全退出。
- [x] 正常动画完整播放 Logo、信号轨、计数/扫描和上下幕帘离场。
- [x] 完成及卸载路径均恢复滚动并移除组件。
- [x] 启动层位于所有现有 Header、导航、转场和 PWA 状态之上，且无横向溢出。
- [x] 聚焦启动首屏测试、全量测试、类型检查、PWA/Tauri 构建和浏览器实渲染通过。

## Out Of Scope

- 不修改后端接口、鉴权、路由结构、页面业务数据或 PWA 缓存策略。
- 不增加跳过按钮、声音、视频或远程素材。
- 不在每次路由切换时重复播放启动首屏。

## Definition Of Done

- 组件、集成、样式和回归测试完成。
- 浏览器验证首次播放、同会话跳过、低动态、尺寸和控制台状态。
- Android Debug APK 构建并安装到已连接真机验证。
- 更新移动端规范与 `docs/superpowers/PROGRESS.md`。

## Validation Result

- 320x720、390x844、448x900 首次播放、离场清理、同会话刷新跳过和横向溢出检查通过，三档控制台均无 warning/error。
- 聚焦测试 5/5、全量测试 159/159、类型检查、PWA 构建、Tauri 构建和 Android aarch64 Debug APK 构建通过。
- 低动态立即退出、存储异常与完成/卸载清理由行为及源契约测试覆盖。
- 优雅版 Android aarch64 Debug APK 已更新安装到华为 TAS-AL00；确认应用进程退出后冷启动为 `COLD`，`MainActivity` 处于前台 `RESUMED`。

## Refinement

- 根据真机观感将第一版偏仪表盘的全屏网格、角标、计数器、三色轨道和横向中线移除。
- 品牌序列收敛为中心展开 Logo、低亮扫光、单条细进度线、极简品牌签名和左右幕布离场。
- 保持约 2 秒时长、现有品牌资产、会话语义、低动态、安全区、滚动锁与清理合同不变。
