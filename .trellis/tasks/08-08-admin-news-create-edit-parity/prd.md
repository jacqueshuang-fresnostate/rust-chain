# 后台新闻新增与编辑页面统一

## Goal

让后台“添加新闻”和“编辑新闻”使用同一套页面结构、字段控件与数据同步规则，避免编辑页仍停留在旧版多语言表单，并保持现有新闻接口、发布/归档动作和权限逻辑不变。

## What I already know

- 新增新闻当前使用 `admin-news-create-layout`，分为“发布设置 / 视觉素材 / 内容编辑”三块，并通过国家下拉框自动确定默认语言。
- 编辑新闻仍使用旧版 `admin-earn-product-layout`，国家、默认语言及翻译元数据均为自由文本输入，并允许新增语言内容。
- 后端创建与更新请求的核心字段一致；更新状态由独立发布/归档接口处理，编辑请求不应提交 `status`。
- 旧编辑页可令顶层 `country_code/default_locale` 与 `content_json.items[0]` 的国家、语言、标题不一致。

## Requirements

- 新增与编辑新闻复用同一个表单组件和同一套视觉分区。
- 桌面端严格采用参考图的上下两层排版：上层左侧为小 Logo、Banner、国家、分类及新增页初始状态，右侧为新闻标题与摘要；下层正文富文本编辑器横跨全部可用宽度。
- 素材区顺序固定为“小 Logo 在左、Banner 在右”；国家与分类同排，初始状态位于其下一行。
- 编辑页沿用同一网格，但不为缺失的初始状态保留空白控件；窄屏按素材、设置、标题、摘要、正文的阅读顺序单列排列。
- 国家均使用后台国家配置接口提供的中文下拉选项，默认语言由所选国家自动确定，不显示自由文本语言字段。
- 标题、国家、默认语言和主内容项中的标题、国家、语言必须同步。
- 编辑新闻切换国家时保留原摘要、正文和视觉素材，只更新国家及默认语言元数据。
- 新增页继续显示初始状态选择；编辑页不显示状态选择，也不改变独立发布/归档流程。
- 保持现有 API 路径和更新请求字段不变。

## Acceptance Criteria

- [x] 新增与编辑 SideSheet 均渲染相同的三段式新闻表单布局。
- [x] 1728px 宽度下，上层左栏显示 Logo/Banner 和国家/分类/状态，右栏显示标题/摘要，正文编辑器在下一行横跨全宽。
- [x] 新闻新增与编辑使用 100vw 全屏 SideSheet，Banner 填满 Logo 右侧网格单元并保持 5:2 比例。
- [x] 小 Logo 位于 Banner 左侧；国家与分类同排；新增页初始状态在下一行，编辑页不显示该控件。
- [x] 窄屏布局退化为无横向溢出的单列阅读顺序。
- [x] 编辑页不再出现“默认语言”“语言”“翻译国家”“翻译标题”和“新增语言内容”等旧版自由文本控件。
- [x] 编辑页加载已有标题、摘要、正文、图片、分类和国家。
- [x] 编辑时切换国家会同步更新请求中的 `country_code`、`default_locale` 及 `content_json` 主内容元数据，同时保留摘要与正文。
- [x] 编辑请求不包含 `status`。
- [x] 新闻动作测试、后台 typecheck、lint、build 和 `git diff --check` 通过。

## Out of Scope

- 不修改新闻后端接口、数据库结构、权限或发布/归档状态机。
- 不新增多国家/多语言新闻编辑能力。
- 不修改新闻列表、详情展示或移动端新闻页面。
