# 平台交易对默认行情：配置与上线交接

## 本轮交付

适用于 HIPPO-USDT 这类 `strategy/internal` 交易对。默认行情不是一条
永久人工策略：无需设置结束时间，也不需要每小时复制策略。

| 情况 | 行为 |
| --- | --- |
| 已启用默认行情，没有生效人工排期 | 持续生成默认行情 |
| 只有草稿、未来或已结束策略 | 继续默认行情 |
| 人工策略生效 | 在分钟边界接管，避免重写半根 K 线 |
| 人工策略暂停、禁用或结束 | 在分钟边界交回已启用的默认行情 |
| 当前生效人工策略运行异常 | 记录错误，不启动第二个竞争生成源 |
| 暂停全部行情或禁用交易对 | 两种生成器均停止 |
| 默认行情未启用 | 不隐式启用，不凭空选择初始价 |

## 后台入口与首次配置

部署后进入 **行情管理 → 交易对 → 对应交易对行的「默认行情」**。

1. 确认交易对为内部/策略类型且已启用。
2. 填写默认参数；没有已归档价格或有效检查点时，必须明确填写起始价。
3. 点击「生成默认行情预览」，核对 60 根分钟样本、范围、成交量和小数精度。
4. 显式勾选默认行情启用，保存时填写原因。保存不会解除「全部暂停」。
5. 重新加载读取实际来源、版本、最近价格/时间及运行错误；同时验证手机端
   ticker、1m、其他周期、盘口与最新模拟成交确实更新。

未配置的既有交易对默认关闭。迁移不会替线上交易对填写价格或自动启用。

### 参数单位

- 波动率：每分钟收盘偏移上限比例，例如 `0.0015` 表示 `0.15%`，不是 `0.0015%`。
- 均值回归：朝持久化锚定价回归的强度，范围 `0..1`。
- 影线强度：基于波动幅度生成上下影线，范围 `0..1`。
- 最低/最高价格：可选正价格边界；超出边界的续接价会报错，不会偷偷修价。
- 最小/最大成交量：每分钟模拟量，数量精度由交易对配置决定。
- 盘口档数：`1..20`。模拟盘口和成交展示不代表真实用户成交。

代码缺省值是波动率 `0.0015`、均值回归 `0.05`、影线 `0.25`、分钟量
`10..20`、20 档，无默认价格和价格上下限。这只是系统初值，不保证某种走势；
若波动小于一个最小价格单位，图上仍可能接近平线。已有异常历史不自动重算。

## 默认行情跟随 BTC 等外部交易对

在同一个「默认行情」侧栏选择 **跟随外部行情**，再明确选择外部交易对
（例如系统目录中的 BTC-USDT）；系统不会自动选第一项或把 BTC 的绝对价格复制给本币。

- 跟随倍率默认 `1`：参考价格涨 1%，本币相对锚定价涨 1%，受价格边界及
  分钟幅度上限约束；允许大于 0 且不超过 3，不支持负倍率或反向跟随。
- 每分钟最大跟随幅度默认 `0.05`（5%），大于 0 且不超过 1；该上限在
  跟随模式的降级阶段也生效。参考过期时间默认 60 秒，可配 15–300 秒。
- 参考只能是已启用的外部行情交易对；自身、平台生成交易对及缺失引用不接受。
  采样来自现有采集归档，不新增交易所连接，也不拿 24 小时涨幅作为逐秒涨跌。
- 参考缺失、停用、过期或冲突时，自动按本币独立参数震荡，并在后台显示原因。
  恢复后以本币已接受价格及当前参考价格重新锚定，不追补中断期间全部涨跌。
- 本币价格上下限、成交量和盘口档数始终生效；参考的真实成交量不会复制到本币。
  分钟和高周期 OHLC 保持同一数据链，跟随模式不预测未来参考高低价。
- 预览使用过去 60 个分钟窗口内的参考观察记录做模型回放，**不是预测未来
  BTC，也不是本币真实历史**；显示范围、使用采样数和降级说明。无参考或超过
  20,000 条上限时明确展示独立兜底样本，不用截断证据冒充完整回放。
- 后台状态是最近读取快照；worker 停止后不会靠面板自动持续检测或通知。
  保存参数仍在新分钟生效，默认启用/人工优先/全部暂停语义保持不变。

旧配置缺少模式字段时保持原独立生成结果。该扩展使用已有版本化 JSON，
不修改已应用的 0124 迁移。发布/回滚时避免混跑不理解跟随状态的旧 worker；
回滚前先暂停跟随来源并确认兼容性。本轮未替线上 HIPPO-USDT 启用或修改配置。

## 连续性与操作区别

- 默认行情首次启动优先使用最新非未来归档，其次有效检查点，最后显式起始价。
  参数更改保留当前分钟，在新分钟生效；同分钟重启复用已持久化的完整形态。
- 人工策略保留已保存的起始价、目标价和路径，**不会自动改成当前价**。
  启用前核对实时价格及人工预览；确认窗口明确提示可能价差及其影响。
  本轮没有新增自动对齐现价模式或实时价差计算器。
- 单条策略暂停不是全部停盘；要停止两种生成源，使用「暂停全部行情」。
  恢复仅解除总暂停，不自动启用默认行情或修改人工策略状态。
- 暂停生成不会撤单、平仓、退款或清除旧缓存。默认生成价格沿用既有订单触发
  与价格归档链；秒合约额外检查来源、租约、版本、代次及最近 60 秒健康归档。
  原结算窗口、结果和退款规则保持不变。
- 启动/重启不补造历史缺口；已登记且紧邻当前分钟的待闭合写入可幂等完成，
  不属于扫描补历史。旧异常历史仍走原管理员预览/确认恢复流程。

## 部署前检查

1. 备份，停止并排空旧模拟行情 worker，再按正常发布流程应用迁移
   `0124_default_market_generators.sql` 和新后端/Web/手机端。
   不混跑缺少交易对级围栏的旧生成器；回滚程序前先暂停新来源并核对兼容性，
   不通过删除迁移或历史记录回滚。
2. 同一平台交易对不要同时路由到外部行情源。此次共同锁协调人工与默认生成，
   不实现外部行情故障转移或外部源竞争接管。
3. 在隔离/预发布环境验证参数、人工接管、暂停恢复和实际业务价格消费者。
   本轮只使用本地夹具，没有线上启用、订单、钱包或结算操作。
4. 线上由管理员确认具体参数并启用；检查逐交易对/逐频道实际时间戳。
   配置面板显示读取时快照，不是持续健康监控或下一切换时间预测器。
