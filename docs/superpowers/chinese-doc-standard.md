# 后端 Rust 中文注释丰富化标准

本文件是「让项目代码功能一目了然」任务的唯一执行标准。所有参与该任务的执行者必须严格遵守。

## 1. 绝对红线

1. **只允许新增或改写注释，禁止修改任何可执行代码。** 不得改动函数签名、类型、表达式、语句、导入、属性宏、`#[cfg]`、测试。唯一允许的改动是 `///`、`//!`、`//` 注释文本本身。
2. **禁止编造。** 必须先读懂函数实现，注释只描述代码真实存在的行为。不确定的行为宁可不写，也不能猜测。
3. **禁止复述函数名。** `/// 获取用户` 配 `fn get_user` 属于无效注释，会被判定为不合格。
4. **禁止批量粘贴同一段注释。** 同一文件内不同函数的注释必须按各自真实的输入、副作用、失败模式区分。
5. **保持 ASCII 标点与既有风格一致。** 沿用仓库既有中文注释风格：陈述句、不使用表情符号、不使用 Markdown 列表符号。

## 2. 注释位置与形式

- 函数、方法、trait 方法：函数上方 `///`，位于 `#[...]` 属性之上。
- 模块：文件顶部 `//!`，说明该文件在限界上下文中的职责边界。
- 函数体内的关键分支、锁顺序、绕过点、历史兼容处理：使用行内 `//`，解释「为什么」而非「做了什么」。
- 结构体、枚举及其非自明字段：`///` 说明业务含义、取值范围与单位。

## 3. 内容要求

每条函数注释按需覆盖以下维度，**首行必须是动词开头的职责概述**：

| 维度 | 何时必须写 | 说明 |
|---|---|---|
| 职责概述 | 总是 | 这个函数在业务上完成什么，首行一句话说清 |
| 输入约束 | 有前置条件时 | 调用方必须保证什么；哪些参数组合非法 |
| 核心规则 | 有算法/判定逻辑时 | 计算口径、状态机迁移、匹配规则、精度处理 |
| 副作用 | 有写操作时 | 写哪些表、改哪些缓存键、发哪些事件、调哪些外部服务 |
| 事务与并发 | 涉及事务/锁时 | 是否在事务内、锁的获取顺序、为何这样排序防死锁 |
| 幂等与重放 | 有幂等键/重试时 | 重复调用的语义，冲突时如何回读 |
| 失败语义 | 有错误分支时 | 返回哪类 `AppError`、失败时是否回滚、是否留下部分写入 |
| 明确的不做 | 易被误用时 | 例如「本函数不发布事件，由调用方在提交成功后广播」 |

## 4. 字符量下限

按函数体行数（`fn` 行到结束大括号）分档，统计的是中文字符数：

| 函数体行数 | 中文字符下限 | 建议行数 |
|---|---|---|
| < 15 行 | 40 | 1-2 行 |
| 15-49 行 | 80 | 2-4 行 |
| >= 50 行 | 120 | 3-6 行 |

下限是底线不是目标。信息密度优先：宁可写满 5 行有效约束，也不要凑字数。

不适用下限的极少数情况：纯 `Default`/`From` 样板转换、单行字段 getter。这类仍需一句准确说明，但可低于下限。

## 5. 正例

```rust
/// 在单个 MySQL 事务中结算一笔现货成交，调用方必须传入同交易对、方向相反且满足限价约束的买卖订单。
/// 事务先按固定顺序锁订单，再以成交幂等键占位，随后按用户/资产稳定顺序锁钱包，避免双向撮合形成死锁。
/// 买方报价资产与卖方基础资产只能从 frozen 扣减，对手资产等额进入 available；每条资金腿、佣金及订单状态均同步写账本。
/// 同一幂等键重放只接受完全一致的订单、价格和数量并返回既有成交；唯一键竞态会回滚后走只读重放，不重复结算。
/// 本函数不发布外部事件；调用者只能在事务提交成功且 `is_new_trade` 为真时广播成交结果。
pub(crate) async fn settle_spot_fill(...)
```

## 6. 反例

```rust
/// 结算现货成交。
pub(crate) async fn settle_spot_fill(...)          // 复述函数名，无任何约束信息

/// 查询数据库并返回结果。
fn load_orders(...)                                 // 空洞，任何函数都适用

/// 处理请求。
fn handle_a(...)
/// 处理请求。
fn handle_b(...)                                    // 批量粘贴，无区分度
```

## 7. 完成后自检

在交付前必须自行执行并确认通过：

```bash
cargo fmt --all -- --check
cargo check --all-targets
```

若 `cargo fmt` 报告差异，运行 `cargo fmt --all` 修正后重新确认。注释过长导致的换行由本人手工排版，保持每行不超过约 120 列。
